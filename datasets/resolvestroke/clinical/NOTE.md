# Note on `clinical/`

The full submission holds **20 clinical acquisitions** (`SP01`–`SP10`, Left/Right), as described
in the parent `README.md`. This repository tracks only the **non-data files** of a submission
(see `datasets/README.md`), and the reconstruction scripts are identical across all
20 subject directories.

Only one representative subject — **`SP02-Left-2`** — is therefore included here, rather than 19
further copies of the same scripts. The remaining acquisitions, along with all `.hdf5` data and
`.png` previews, are distributed with the dataset itself.
